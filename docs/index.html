What it finds.

Eight views, each sorted biggest first.

  • Large filesAnything over 100 MB, biggest first.
  • UnusedNot opened or changed in N months.
  • CachesSafe to clear, or review first.
  • ClutterOld downloads, installers, node_modules and venvs, iPhone backups.
  • ApplicationsLast opened, leftovers in Library, uninstall.
  • DuplicatesByte-for-byte identical copies.
  • ExplorerDrill into any folder by size.
  • Outside your homeWhat makes up “macOS & other”.

Safety model.

What each action does, and what it will never do.

ActionReversibleConfirmation
Move to Trash⌘⌫tYes, with UndoNone needed
Delete permanentlyxNoAlways warns first
Clear cacheNoAlways warns first
Empty TrashNoAlways warns first
System & standard foldersRefusedCan’t be removed at all

In the app, Return cancels a warning. In the terminal, only the y key confirms; a mouse click can’t. Keychains, Preferences, ~/.ssh and anything inside a package such as a Photos library are refused too.

What the installer does.

Nothing else is installed: no Homebrew, no background services. Re-run to update.

  1. Checks your Mac

    macOS 14 or later, Apple Silicon or Intel.

  2. Installs Python 3, only if it’s missing

    The official python.org package, signature-checked against the Python Software Foundation. Asks for your password once.

  3. Installs the app

    The latest release, verified against its published checksum, into /Applications/MacSafe.app.

  4. Adds macsafe

    Into ~/.local/bin. It replaces the older storagemon command and Storage Monitor.app if you had them.

Full Disk Access & uninstall

For complete totals, turn on MacSafe (and Terminal, for macsafe) in System Settings › Privacy & Security › Full Disk Access. The app walks you through it the first time it opens, before the first scan, and updates keep it on.

curl -fsSL https://gabrielesarria167-ai.github.io/MacSafe/install.sh | bash -s -- --uninstall

Removes the app, the command and their caches. Python stays.
