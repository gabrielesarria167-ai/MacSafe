      Two ways in, one scanner.

      A Mac app and the macsafe terminal dashboard read the same scan. Both open instantly with the last one and rescan in the background when it’s older than 15 minutes. Both keep themselves up to date.

      The Mac app

      For browsing, sorting and bulk cleanup. Select any part of the disk to see what’s in it, or review anything under Free up space.

      ⌘⌫
      Move to Trash
      ⌘Z
      Put it back
      ⌘R
      Rescan

      The macsafe command

      A quick check without leaving Terminal. Click a slice of the ring or any row, or use the keyboard.

      --report
      Print a summary and exit
      --update
      Install the latest version now
      --app
      Open the Mac app
      --no-mouse
      Leave clicks to the terminal for selecting text

      What it finds.

      Each view names a culprit and sorts it biggest first.

      • OverviewThe whole disk at once, and what you could free.
      • ExplorerDrill into any folder by size.
      • Large filesAnything over 100 MB.
      • UnusedNot opened or changed in months.
      • DuplicatesByte-for-byte identical copies.
      • CachesSafe to clear, or review first.
      • ClutterOld downloads, installers, node_modules and virtualenvs, iPhone backups.
      • ApplicationsWhen you last opened each app, its leftovers, and uninstall.
      • Outside your homeWhat makes up macOS & other.

      Careful by default.

      The safe path is the default path. One line tells you what each action does: solid means you can undo it, dashed means it asks first, struck means MacSafe won’t do it.

      StateActionWhat happens
      Move to Trash⌘⌫Reversible. Undo puts it back where it was.
      Delete permanentlyAlways warns first. Return cancels the warning.
      Clear cacheAlways warns first. Apps rebuild what they need.
      Empty TrashAlways warns first.
      System and standard foldersRefused outright, along with Keychains, Preferences, ~/.ssh and anything inside a package such as a Photos library.

      In the terminal only the y key confirms a warning; a mouse click can’t.

      What the installer does.

      Nothing else gets installed: no Homebrew, no background services. Run it again any time to update.

      1. 1

        Checks your Mac

        macOS 14 or later, Apple Silicon or Intel.

      2. 2

        Adds Python 3, only if it’s missing

        The official python.org package, signature-checked against the Python Software Foundation. Asks for your password once.

      3. 3

        Installs the app

        The latest release, checked against its published checksum, into /Applications/MacSafe.app.

      4. 4

        Adds macsafe

        Into ~/.local/bin. It replaces the older storagemon command and Storage Monitor.app if you had them.

      Prefer a regular download

      Open the disk image and drag MacSafe into Applications. The app isn’t notarized, so the first launch shows a “could not verify” warning once: click Done, then open System Settings › Privacy & Security and choose Open Anyway. Needs Python 3 from python.org.

      Download for Mac

      Full Disk Access

      For complete totals, turn on MacSafe (and Terminal, for macsafe) in System Settings › Privacy & Security › Full Disk Access. The app walks you through it before the first scan, and updates keep it on.

      Uninstall

      Removes the app, the command and their caches. Python stays.

      curl -fsSL https://gabrielesarria167-ai.github.io/MacSafe/install.sh | bash -s -- --uninstall
