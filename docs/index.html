See what's filling your Mac, then clean it up safely.

A Mac app and a terminal dashboard that show where your storage went: big files, forgotten downloads, old caches and apps you never open.

Install · paste into Terminal 
curl -fsSL https://gabrielesarria167-ai.github.io/MacSafe/install.sh | bash

What the installer does

  1. Checks your Mac

    macOS 14 or later, Apple Silicon or Intel.

  2. Installs Python 3, only if it's missing

    Storage Monitor's scanner runs on Python. If your Mac doesn't have it, the installer downloads the official package from python.org, checks that it's signed by the Python Software Foundation, and asks for your password once to install it.

  3. Installs the app

    Downloads the latest release, checks it against its published checksum, and puts it in your Applications folder.

  4. Adds the storagemon command

    The terminal dashboard, for a quick look without leaving Terminal.

Nothing else is installed: no Homebrew, no background services. Run it again any time to update.

What it finds

Large filesAnything over 100 MB, biggest first.
UnusedFiles and folders untouched for months.
CachesMarked safe to clear or review first.
ClutterOld downloads, installers, node_modules, iPhone backups.
AppsWhen you last opened each one, and what it left in Library.
DuplicatesByte-for-byte identical copies.
ExplorerDrill into any folder by size.
Outside your homeWhat makes up “macOS & other”.

⚠Moving to the Trash can be undone. Deleting permanently always shows a warning first, and system folders can't be removed at all.

Prefer a regular download?

The app isn't notarized by Apple, so a file downloaded in a browser gets macOS's “could not verify” warning the first time. The Terminal install above avoids it. To open the download anyway:

  1. Unzip it, drag Storage Monitor.app to Applications and open it. Click Done on the warning.

  2. Open System Settings › Privacy & Security and scroll down.

  3. Click Open Anyway next to Storage Monitor and confirm. macOS remembers the choice.

You'll need Python 3 from python.org if the app says it's missing.

After installing

For complete results, let Storage Monitor read every folder. Without this, macOS hides some folders from it and the totals come out low.

  1. Open System Settings › Privacy & Security › Full Disk Access.

  2. Turn on Storage Monitor. For the storagemon command, also turn on Terminal.
